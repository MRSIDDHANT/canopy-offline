Canopy Offline · version 0.3.0-alpha

Your trees. On your computer.

Open this HTML file in Firefox, Chrome or Edge, then choose Open tree and select an IQ-TREE .treefile. No installation, account, server, internet connection or external library is needed. There are no uploads or analytics; the page blocks network connections.

Explore & edit

Choose rectangular, circular or equal-angle radial layouts. Drag to pan and use the wheel to zoom. In rectangular view, the wheel magnifies rows; Shift + wheel magnifies both axes. Readable tips opens a scrollable region at readable spacing. Select endpoints or labels to inspect, collapse, rotate, color, focus or reroot. Undo restores the last 15 editing operations.

Branch-length mode uses actual lengths; a missing length is drawn as 1 and reported in the status. Cladogram mode uses equal edge lengths. Radial layout is a rooted equal-angle construction; rerooting changes its appearance. Collapsing and focusing only affect display, not exported tree topology.

Copy labels & highlight clades

Pause over a node, branch, or tip label to open its clade panel. Move into the panel to select text, or click a node to pin the panel. Choose displayed labels, protein names, original IDs, or an ID/name TSV table, then use Copy all. Every descendant tip is included, even when collapsed or too dense to display. Unmapped names fall back to their original IDs. Duplicate labels are retained. Text is one line per tip; tabs and line breaks inside names are replaced with spaces.

Pin keeps the panel fixed while you move the pointer. Focusing the text box also pins it. If the browser blocks clipboard access for a local file, the text remains selected for Ctrl+C (Cmd+C on Mac). You can also download the complete list.

Choose a color and Highlight clade to shade the node and its descendant branches and labels. Backgrounds default to 60% opacity (40% transparent); the slider lets you change this, including to 40% opacity if you want 60% transparency. The shading is behind the branches and text: rounded bands in rectangular view, fans in circular view, and clade envelopes in radial view. Multiple highlights can overlap. Use Remove, Clear all highlights, or Undo to clear them. Highlights follow the node's current descendants after rerooting; a focused subtree retains highlights inherited from its ancestors. Hidden child highlights reappear when expanded.

Background highlights are saved in sessions and included in PNG and SVG exports. Newick contains biological tree data and does not store highlight styling.

Rename or hide a node name

Select a node, or use its pinned hover panel, enter a display name and choose Rename. The new name is shown immediately. Show name and Hide name override the global label switches for that node; Use global visibility restores their control. Explicitly shown labels remain visible when automatic density filtering hides other names. Reset name restores the original or mapped name. These edits support Undo and saved sessions. Original IDs, branch lengths and support values are preserved. The renamed Newick export applies display names to tips; internal names and support values remain the original tree labels.

Branch colours and typography

Select a node, then use Branch colour to colour its incoming branch, its whole clade, or all branches. Reset restores inherited or imported annotation colours. Branch colours and text colours are independent. Under Name style & position, choose the node base or the tip of the longest visible path from that node and click Apply name style. Length mode uses cumulative branch lengths (missing lengths count as 1); otherwise it uses the number of edges. Collapsed clades use their visible endpoint. A name placed at the longest branch tip follows any existing tip label. Full rectangular exports and Readable tips increase row spacing for larger fonts.

Tree text style sets styles for tip labels, node/support names, legend text, scale-bar text, textbox defaults, or all tree text. Each label and textbox can have its own override. Choose Arial, Helvetica, Calibri, or Times New Roman, size 6–96, bold, italic, and text colour. Fonts are taken from your computer; unavailable fonts use a local serif or sans-serif fallback. Exports use the same styles. SVG keeps text editable and may use a fallback when opened on a computer without the selected font.

Textboxes

Choose Add textbox or Text ＋, edit the content and style on the left, then click Apply changes. Newlines create multiple lines. Click a textbox to select it and drag to move it. With the tree focused, arrow keys nudge it by one pixel (Shift: ten), Enter focuses its editor, and Delete removes it. Boxes move with tree panning and keep a separate position for each layout. On the first switch to a new layout they appear near the tree centre; drag to place them. Textboxes, colours, positions, and typography support Undo and saved sessions. Image exports include all boxes; Full SVG and full-tree raster exports expand to include their bounds. Newick does not store display styling.

Optional support circles

Enable support circles to display existing bootstrap/support values as light circular gauges. Their filled portion shows the support percentage, and the corner legend explains the fill. Choose which slash-separated value to use and whether values use the 0–100 or 0–1 scale. Invalid or out-of-range values are skipped and counted. The feature is off by default, and support extraction is not run until enabled. Opening a tree or a saved session switches it off again. No statistical bootstrap replicates are calculated by the viewer. Renaming a node does not change its support value.

High-resolution images

Choose PNG or JPEG, the view or full visible tree, print width in inches, and 300, 600, 1200 or custom DPI (72–2400). Pixel width = print width × DPI. The tree is drawn again at that resolution, rather than enlarging a screenshot. PNG and JPEG files include physical-resolution metadata. Background highlights, hidden/renamed labels, enabled support circles and their legend are included. SVG exports remain vector graphics and can be scaled without losing detail. Raster exports are limited to 16,384 pixels per side and 64 megapixels; for a very tall tree, collapse clades, export the viewport, or use Full SVG.

Export & sessions

View exports use the current canvas region. Full SVG includes all tips in the current focused/collapsed view and may be very tall for thousands of tips. Newick exports the entire tree, including hidden tips. Sessions save tree edits, mapping, view and colors to JSON; reopen them with Open saved session. There is no automatic persistence: save before closing. Long labels are shortened when tracks are shown; turn tracks off for full label text in SVG exports. Undo covers tree edits, not annotation imports.

Scientific details

Newick parsing supports quoted labels, doubled quote escapes, comments, multifurcations, scientific-notation lengths and IQ-TREE slash-separated internal supports. Rerooting inserts a root halfway along the selected edge, preserves pairwise path lengths when supplied, and treats numeric internal labels (including 95/100) as edge support. Non-numeric internal names and raw comments remain node metadata; comments are not interpreted. An artificial unlabeled degree-two old root is suppressed when it has no comments. Rerooting an input with a unary root is rejected rather than introducing a spurious tip.

Comparison requires exactly matching, unique original tip names. It ignores branch lengths, support and rooting, and reports the symmetric difference between nontrivial unrooted splits. Normalized RF = RF / (split count A + split count B). Polytomies are allowed and affect split counts. This is not a test of alignment quality.

Rendering & limits

WebGL batches branch geometry for accelerated drawing. Layout, parsing, hit testing, tracks and text run on the CPU. The browser may use a software WebGL renderer; check Firefox about:support to confirm physical GPU use. If WebGL is unavailable, Canvas 2D draws branches. A Slurm GPU allocation or SSH X11 session does not ensure hardware rendering.
